

# CodeCloud IDE - סביבת פיתוח אונליין

## סקירה
אפליקציית ווב (IDE) שרצה בדפדפן, ללא צורך בהתקנה על המחשב. תומכת בעריכה והרצה של קוד במגוון שפות: Python, JavaScript/React, Java, C#, Node.js, HTML/CSS. הרצת הקוד תתבצע דרך API חיצוני (Judge0) כך שהכל עובד בענן.

> **הערה חשובה**: אם יש חסימות רשת חזקות מאוד, הגישה ל-API של הרצת הקוד עשויה להיחסם גם כן. האפליקציה עצמה תעבוד בדפדפן ללא בעיה, אך הרצת קוד דורשת חיבור לשרת חיצוני.

---

## שלב 1: עורך קוד מתקדם
- עורך קוד מבוסס Monaco Editor (אותו עורך שמשמש את VS Code)
- תמיכה ב-Syntax Highlighting לכל השפות: Python, JS, TypeScript, Java, C#, HTML, CSS
- השלמה אוטומטית (autocomplete) בסיסית
- מספור שורות, הדגשת סוגריים, חיפוש והחלפה
- בחירת ערכת נושא (Dark/Light mode)

## שלב 2: ניהול קבצים ופרויקטים
- עץ קבצים בצד שמאל (כמו ב-VS Code)
- יצירה, מחיקה ושינוי שם של קבצים ותיקיות
- תמיכה במספר טאבים פתוחים
- שמירת קבצים ב-LocalStorage של הדפדפן (ללא צורך בשרת)

## שלב 3: הרצת קוד דרך API חיצוני
- חיבור ל-Judge0 API להרצת קוד ב-Python, Java, C#, JavaScript, Node.js
- פאנל Output/Console בתחתית המסך שמציג תוצאות
- תמיכה בהזנת Input לתוכנית
- אינדיקטור טעינה בזמן הרצה
- הצגת שגיאות compile/runtime בצורה ברורה

## שלב 4: תצוגה מקדימה ל-HTML/React
- פאנל Preview בצד ימין להצגת HTML/CSS/JS חי
- עדכון אוטומטי של התצוגה בזמן כתיבה
- תמיכה בתצוגת React פשוטה דרך iframe

## שלב 5: פיצ'רים נוספים
- ייצוא וייבוא פרויקטים כ-ZIP
- קיצורי מקלדת (Ctrl+S, Ctrl+Enter להרצה)
- Terminal מדומה להצגת פלט
- תמיכה בעברית (RTL) בממשק
